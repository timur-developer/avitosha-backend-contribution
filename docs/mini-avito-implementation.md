# Mini-Avito — итог реализации и ручная проверка

## Что внедрено

- Mini-Avito: публичный каталог и карточки, категории, черновики и «Мои объявления», редактирование, публикация/снятие с публикации, избранное, уникальные просмотры, первое сообщение продавцу и demo-покупка.
- Игровая интеграция использует существующий `ProcessActionWithinTx`: сервер определяет тип действия, категорию, XP и metadata; эффект изменяет питомца, XP, характер, FIRST_ROOM, награды и отправляет целевые WebSocket-события после commit.
- Anti-abuse: ownership, запрет self-action/self-purchase, уникальность favorite/first message/view/day/quality criterion/deal, server-only marketplace marker, `eventId` и журнал идемпотентных запросов.
- Контракты описаны в OpenAPI; gateway вызывает game-service по gRPC; WebSocket сохраняет envelope `{ "events": [...] }`.
- MVP-ограничения: demo-покупка доступна только для seed demo-listing и один раз на покупателя; она не меняет общий каталог. `X-User-ID` допустим только в demo/dev. Realtime hub in-memory, без гарантированной межинстансовой доставки.

## Пользовательский путь

Лендинг/регистрация → экран питомца → 5 уникальных просмотров furniture → favorite → первое сообщение продавцу → создание своего объявления с непустым названием и ценой > 0 → публикация → demo-покупка с `deliveryUsed=true`. Фото и описание от 150 символов повышают качество объявления, но не блокируют публикацию. Каждый зачтённый шаг возвращает `actionResult`; FIRST_ROOM продвигается, начисляются XP и открываются DESK, LAMP, CHAIR, PLANT, POSTER.
